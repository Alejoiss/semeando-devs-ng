# Gestão de Cupons

## 1. Objetivo do Fluxo
Permitir que a equipe administrativa crie, edite e gerencie cupons de desconto promocionais para incentivar assinaturas do plano PRÓ da plataforma.
*(Nota: Funcionalidade atualmente **Em Construção** na plataforma).*

## 2. Público-Alvo
Administradores da plataforma (Equipes de Marketing, Vendas e Suporte).

## 3. Passo a Passo (Jornada do Usuário)
1. O administrador acessa a página de Cupons (`/admin/cadastro-de-cupons`).
2. Atualmente, o sistema exibe uma tela estilizada de *placeholder* informando: **"Esta seção está em construção."**
3. *[Fluxo futuro]*: O administrador visualizará uma lista de cupons ativos/inativos e possuirá um formulário para criar um novo cupom definindo (Código, Desconto %, Data Limite, Limite de Usos).

## 4. Gatilhos de Marketing e Comunicação
- *[Futuro]*: A base de cupons criada aqui será o motor para campanhas de e-mail marketing (ex: cupons de Black Friday, cupons de reativação de alunos inativos).
